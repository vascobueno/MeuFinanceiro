# V5 — Telas

Todas as telas devem ser implementadas com PrimeNG + Tailwind CSS. Os mockups V5 cobrem um
subconjunto representativo das telas e demonstram a linguagem visual: sidebar/drawer, cards
financeiros, tabelas, badges, filtros, dialogs e autocomplete. Telas sem mockup próprio devem
seguir os mesmos princípios do design system (docs/21-telas.md).

A implementação deve usar componentes PrimeNG reais, não HTML estático.
