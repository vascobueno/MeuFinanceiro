# 11 — Projeção Financeira

Permitir consultar qualquer data futura.

Mostrar separadamente:
1. Saldo projetado das contas correntes.
2. Saldo projetado dos investimentos.
3. Patrimônio financeiro projetado.

Contas consideram lançamentos futuros, recorrências, parcelas, faturas, aplicações e resgates.

Investimentos consideram posição atual, aplicações, resgates e rendimentos quando confiáveis.

Patrimônio = contas + investimentos somente para apresentação consolidada.

Exibir composição cronológica e alertar saldo negativo.
