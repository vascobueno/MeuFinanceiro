# 16 — Importação Inicial

Fluxo:
Excel -> Upload -> Validação -> Prévia -> Importação -> Relatório -> Conferência.

Guardar arquivo original, hash, usuário, data/hora e resultado.

Não importar o mesmo arquivo novamente sem confirmação.

Validar datas, valores, contas/cartões, categorias, duplicidades e parcelamentos.

Após validação, Excel deixa de fazer parte do fluxo operacional.
